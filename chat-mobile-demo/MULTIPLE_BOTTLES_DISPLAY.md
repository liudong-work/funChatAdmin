# 多瓶子独立显示功能

## 📝 功能说明

**更新时间**: 2025-10-16

### 核心特性

当海里有多个漂流瓶时，**每个瓶子都会在屏幕上显示为独立的图标**，用户可以直接点击任意瓶子进行捞取。

---

## 🎯 显示方式

### 瓶子数量与位置对应关系

| 瓶子数量 | 显示位置 |
|---------|---------|
| 1 个 | 中间 (45%) |
| 2 个 | 左侧 (15%) + 中间 (45%) |
| 3 个 | 左侧 (15%) + 中间 (45%) + 右侧 (75%) |

## 👆 用户交互

### 操作流程

1. **查看** - 主页显示海里所有可用的瓶子（最多3个）
2. **选择** - 直接点击任意一个瓶子图标
3. **捞取** - 系统自动捞取被点击的瓶子
4. **查看内容** - 弹窗显示瓶子内容

### 优势

- ✅ **更直观** - 一眼看到有几个瓶子
- ✅ **更快捷** - 直接点击，无需二次选择
- ✅ **更有趣** - 多个瓶子在海面漂浮的视觉效果
- ✅ **更自由** - 可以自由选择任意一个瓶子

## 🔧 技术实现

### 后端配置

**文件**: `backend/src/server-with-db.js`

```javascript
// API: GET /api/bottle/check
const bottles = await Bottle.findAll({
  where: {
    status: 'sea',
    sender_uuid: { [Op.ne]: myUuid }
  },
  order: [['created_at', 'ASC']],
  limit: 3  // 最多返回3个瓶子
});
```

### 前端实现

**文件**: `HomeScreen.js`

#### 关键代码

```javascript
// 渲染多个瓶子
{availableBottles && availableBottles.length > 0 && availableBottles.map((bottle, index) => {
  // 为每个瓶子计算不同的水平位置
  const positions = [
    { left: '15%' },  // 左侧
    { left: '45%' },  // 中间
    { left: '75%' }   // 右侧
  ];
  const position = positions[index % 3];
  
  return (
    <TouchableOpacity 
      key={bottle.uuid}
      style={[styles.bottleContainer, position]}
      onPress={() => handleBottleClick(bottle)}
    >
      <Animated.View style={[styles.bottle, bottleTransform]}>
        <Image source={require('./assets/bottle.png')} />
      </Animated.View>
    </TouchableOpacity>
  );
})}
```

#### 点击事件处理

## 🎨 动画效果

所有瓶子共享相同的漂浮动画：

- **上下浮动**: 2秒周期
- **左右移动**: 8秒周期
- **倾斜旋转**: 4秒周期

创造出自然的海面漂浮效果。

## 📈 性能考虑

- **渲染优化**: 使用 `map()` 动态渲染，避免重复代码
- **唯一标识**: 每个瓶子使用 `bottle.uuid` 作为 key
- **位置计算**: 使用简单的数组索引取模运算
- **动画共享**: 所有瓶子共享相同的动画值，减少内存占用
